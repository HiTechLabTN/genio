Documentation

Extend Genio with custom agents, MCP servers, and Docker sandboxes.

01 Quick Start

# Clone and setup git clone https://github.com/HiTechLabTN/genio.git cd genio && ./bootstrap.sh # Run autonomous pipeline python3 core/executive_director.py --auto --prompt "Your Lab Topic"

02 Writing Custom Agents

from core.executive_director import BaseAgent, PlanNode, NodeResult class MyCustomAgent(BaseAgent): async def run(self, node: PlanNode, ctx) -> NodeResult: # Your custom logic here result = await do_something(node.params) return NodeResult(node.id, True, output=result)

03 Model Context Protocol (MCP) Integration

# Register an MCP server as a tool provider from core.model_router import ModelRouter router = ModelRouter() router.register_mcp_server( name="my-tools", url="http://localhost:3001/mcp", tools=["search_docs", "run_test"] )

04 Custom Docker Sandbox

# Add a custom sandbox image in config.py from config import SandboxConfig custom = SandboxConfig( image="my-org/lab-tools:latest", wan_subnet="172.30.0.0/24", lan_subnet="192.168.100.0/24" )
